## Открытый вопрос — хватит ли двух источников

`novosti_efir` был единственным источником и подолгу простаивал (пример: 4.5
часа тишины ночью 2026-07-05). `toporlive` включён обратно в эту сессию — если
объём 12 постов/день всё ещё не набирается, следующий кандидат — `novosti`
(id=1, тоже сейчас выключен).

**Обновление (2026-07-05, позже в тот же день) — источники снова поменяны по
прямому запросу пользователя**: `toporlive` (id=7) выключен, `postnews`
(id=8, VK-группа `152992737`, https://vk.ru/postnews) включён вместо него в
БД на VPS (`data/app.db`, прямой SQL — источники не в config.yaml, не
задеплоены через git). **Пользователь предупреждён и explicitly принял
риск**: `VK_USER_TOKEN` по-прежнему забанен (`[5] User authorization failed:
user is blocked` — проверено живым вызовом `wall.get` на эту группу прямо на
VPS перед переключением), то есть `postnews` физически не будет фетчиться,
пока токен не заменят на рабочий. **Фактически сейчас у пайплайна снова
только ОДИН реально рабочий источник — `novosti_efir`** (TG). Локальная
`data/app.db` на этой машине — отдельная неактуальная копия без `postnews`
и с другими значениями `enabled`, НЕ является источником истины (прод берёт
конфиг из своей БД на VPS, деплой синкает только `app/`+`prompts/`) — не
путать при следующей проверке.
