Задача: определить, является ли текст ниже новостной публикацией, и оценить её ценность для новостного канала.

Источник: {{SOURCE}}
Ключевые темы канала (белый список): {{KEYWORDS}}

Текст публикации:
"""
{{TEXT}}
"""

Проверь по порядку:
1. Это новость (событие, факт, происшествие), а не реклама/розыгрыш/конкурс/опрос/вакансия/закреп/продажа?
2. Есть ли пересечение с ключевыми темами канала?
3. Насколько эта новость свежая и значимая сама по себе — без раздувания важности?

Оцени по шкале 0–100:
- 90–100: событие федерального/международного масштаба, высокая вероятность вирусности.
- 70–89: значимая новость по теме канала.
- 40–69: рядовая новость, есть некоторая ценность.
- 0–39: не новость, реклама, малозначительное событие или дубль общеизвестного факта.

Верни СТРОГО валидный JSON без пояснений вокруг него, в точности такого формата:

{
  "is_news": true,
  "category": "категория одним-двумя словами",
  "score": 0,
  "reasons": ["причина 1", "причина 2"],
  "reject_reason": null
}

Если is_news = false — заполни reject_reason коротким объяснением (например: "реклама", "розыгрыш", "не новость"), а score выставь ниже 40.
