Придумай 3 варианта заголовка для новости ниже. Используй формулу ВИСП: Выгода/значимость для читателя + Интрига + Срочность + Причастность (чем это касается аудитории).

Стиль: {{STYLE}}

Текст новости (уже переписанный):
"""
{{TEXT}}
"""

Правила:
- Обычный регистр — не Title Case ("Цены на нефть выросли", а не "Цены На Нефть Выросли").
- Без эмодзи.
- Без кликбейта, который не подтверждается текстом (без "вы не поверите", если дальше в тексте нет ничего шокирующего).
- Конкретика — цифра, имя, место — вместо общих слов.
- Длина каждого варианта — не больше 12 слов.

Верни строго JSON без пояснений:

{
  "headlines": ["вариант 1", "вариант 2", "вариант 3"]
}
