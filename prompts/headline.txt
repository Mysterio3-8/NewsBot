Придумай 3 варианта ХУКА-заголовка для новости ниже. Хук — это крупная надпись, которая ляжет ПОВЕРХ фото поста, поэтому он должен цеплять взгляд с первой секунды и мгновенно передавать суть.

Стиль: {{STYLE}}

Текст новости (уже переписанный):
"""
{{TEXT}}
"""

Каким должен быть хук:
- КОРОТКИЙ и хлёсткий: 3–7 слов. Это не полный заголовок, а удар по сути.
- Законченная мысль: подлежащее + действие (кто/что → сделал что). НЕ обрывок, НЕ просто тема.
- Конкретика вместо общих слов: место, кто, цифра, если есть в тексте.
- Сильный глагол действия («вымогают», «атаковали», «эвакуировали», «сбили»), а не вялое «произошло/сообщается».
- Только правда из текста — без кликбейта, которого дальше нет.
- Обычный регистр (не Title Case), без эмодзи, без точки в конце.

Хорошие примеры хуков (не копируй, ориентируйся на форму):
- Мошенники в банкоматах вымогают деньги
- Удмуртия отбила массовую атаку дронов
- ВСУ ночью атаковали российские города
- В Ростове при ударе дрона погибла семья

Плохие примеры (так НЕ надо):
- «Атака БПЛА в Удмуртии» — обрывок, нет действия
- «Важное событие в регионе» — пусто, нет конкретики
- «Новости дня» — ни о чём

Верни строго JSON без пояснений:

{
  "headlines": ["вариант 1", "вариант 2", "вариант 3"]
}
