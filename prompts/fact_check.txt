Проверь текст ниже на признаки манипуляции, фейка или непроверяемых утверждений. Ты не ищешь информацию в интернете — только анализируешь сам текст на внутренние противоречия и типичные признаки недостоверности.

Текст:
"""
{{TEXT}}
"""

Проверь:
1. Есть ли утверждения без указания источника там, где источник обязателен (статистика, цитаты, "по данным...")?
2. Есть ли эмоционально нагруженные формулировки, которые подменяют факт мнением ("шокирующая правда", "все скрывают")?
3. Есть ли внутренние противоречия (цифры/даты не сходятся между собой в рамках одного текста)?
4. Есть ли признаки заголовка, не соответствующего содержанию (если заголовок передан отдельно)?

Верни строго JSON:

{
  "suspicious": false,
  "issues": ["описание проблемы 1"],
  "confidence": 0
}

"confidence" — от 0 до 100, насколько ты уверен в своей оценке. Если текст выглядит как обычная новость без признаков манипуляции — suspicious: false, issues: [].
